# Skills Personalizadas do Codex

Este projeto contem minhas skills personalizadas do Codex.

Essas skills sao usadas para estender o Codex com instruções reutilizáveis, fluxos de trabalho e orientações específicas de projeto que me ajudam a trabalhar com mais velocidade e consistência nas minhas tarefas de desenvolvimento.

## Objetivo

- Manter minhas skills personalizadas do Codex organizadas em um unico lugar.
- Facilitar a manutenção, o versionamento e a melhoria das skills ao longo do tempo.
- Documentar comportamentos, convenções e fluxos de trabalho reutilizáveis para o Codex.

## Conteudo

Cada pasta neste repositório pode representar uma skill personalizada do Codex ou arquivos auxiliares relacionados.
